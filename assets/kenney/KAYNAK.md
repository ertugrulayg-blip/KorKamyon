# Kenney modelleri (CC0)

Hepsi Kenney (https://kenney.nl) tarafından **CC0** (kamu malı) lisansıyla yayınlanmıştır: ticari kullanım serbest, atıf zorunlu değil.
https://creativecommons.org/publicdomain/zero/1.0/

- `racing/` — GitHub `KenneyNL/Starter-Kit-Racing` (orman, çadır, boş arazi karoları)
- `city/` — GitHub `KenneyNL/Starter-Kit-City-Builder` (küçük binalar)
- `car/` — Car Kit 3.1 (polis, arabalar, koni, kutu, lastik). Paketin `License.txt` dosyası CC0 der.
- `nature/` — Nature Kit 2.1 (ağaç, kaya, çalı, çiçek, kütük). Paketin `License.txt` dosyası CC0 der.

Car Kit ve Nature Kit'in tamamını proje sahibi kenney.nl'den indirdi; depoya yalnızca kullanılan modeller alındı.
